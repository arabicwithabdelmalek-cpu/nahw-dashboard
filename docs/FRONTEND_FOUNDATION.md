# تأسيس واجهة المنصة التعليمية — Phase 1A

> 10 نوفمبر 2026 — **تغيير واجهة وتقسيم ملفات فقط**؛ لم يحدث ترحيل بيانات، ولم تُنشأ أي جداول جديدة في Supabase.

## الهدف

فك ارتباط اسم النظام العام بكتاب «النحو الواضح»، مع الحفاظ على كافة الفصول والطلاب والنتائج وملفات HTML الموجودة. أصبح الاسم الظاهر مؤقتًا **«المنصة التعليمية»**؛ ويظل «النحو الواضح» اسم المادة/المنهج القديم وليس اسم كل المنصة.

## ما تغير بالفعل

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل HTML صغير يحمل الخطوط والملفات بالترتيب؛ لم يعد يحتوي JavaScript/CSS الداخليين الكبيرين |
| `assets/css/app.css` | أنماط التصميم الأصلية، مع استخدام خط Cairo لواجهة المستخدم |
| `assets/js/platform-config.js` | إعداد الاسم العام `window.EDU_PLATFORM.name` والوصف واسم المادة القديمة |
| `assets/js/supabase-config.js` | إعداد Supabase الحالي، بالمفتاح العام `anon` فقط، دون أي مفتاح خادمي |
| `assets/js/core.js` | أدوات قراءة وتصحيح وعرض الواجبات التاريخية الموجودة **دون تغيير منطقها** |
| `assets/js/app.js` | شاشات الإدارة والمعلم والطالب واتصالات قاعدة البيانات الحالية |

ترتيب الملفات في `index.html` إلزامي:

1. Supabase JavaScript CDN.
2. `platform-config.js`
3. `supabase-config.js`
4. `core.js`
5. `app.js`

**لتغيير اسم المنصة لاحقًا:** عدّل `name` داخل `assets/js/platform-config.js`، دون تعديل شاشات تسجيل الدخول والطالب والمدير المتعددة. سيحدّث السكربت عنوان المتصفح تلقائيًا. لا تُعدّ هذه إعدادات قاعدة بيانات أو إعدادات مدير قابلة للتعديل من لوحة التحكم بعد.

**لتغيير الألوان والخطوط:** راجع `assets/css/app.css`. يستخدم نظام التنسيق الحالي متغيرات CSS للألوان وأنواع الخطوط. لا تُحدّث أو تُحذف مكتبة الواجبات القديمة لمجرد تغيير الخط.

## ما بقي دون تغيير

- مفاتيح وURL مشروع Supabase الحالي، وواجهات Auth/RPC.
- أسماء الجداول والحقول واستدعاءات الجلب والحفظ والحذف.
- جميع مسارات hash مثل `#/classes` و`#/students` و`#/lesson/...`.
- آلية استيراد واجبات HTML القديمة وعرضها والنتائج المرتبطة بها.
- ملفات قاعدة البيانات وStorage وRLS؛ **لم يتم تعديل أي منها**.
- الواجهة العامة الديناميكية وفهرس المواد المنشورة **لم تُبنَ بعد**؛ لا يجوز عرض بيانات وهمية كأنها مقررات حقيقية.

## مخاطر ما زالت موجودة

- عرض HTML القديم يستخدم iframe بدون sandbox؛ لم يُعالج ذلك ضمن عملية التقسيم خوفًا من كسر التوافق، ويلزم اختبار توافق/عزل مستقل قبل تعميم رفع HTML جديد.
- إنشاء الحسابات والأدوار والتحكم في الجداول يعتمد على سياسات Supabase غير المفحوصة حتى الآن.
- الملف `assets/js/app.js` لا يزال كبيرًا؛ تقسيمه أكثر يتطلب اختبارات تكامل مع حسابات حقيقية، وليس مجرد إعادة كتابة شكلية.
- الاسم العام قابل للتعديل في ملف الإعدادات **فقط** الآن؛ ربطه بإعدادات المدير سيحتاج backend وجدول إعدادات آمن.
