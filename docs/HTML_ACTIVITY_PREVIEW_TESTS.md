# سجل فحص معاينة أنشطة HTML — المرحلة التجريبية

**التاريخ:** 10 نوفمبر 2026  
**الفرع:** `feat/html-activity-preview-contract`  
**النطاق:** معاينة محلية فقط، دون تغيير Supabase أو ملفات الطلاب القديمة.

## 1. اختبار وحدة العارض — 21 من 21 ناجحة

- رفض ملفات بامتدادات غير `.html` و`.htm` ورفض المستند غير المكتمل.
- رفض ملف يزيد على ٢ ميجابايت.
- إنشاء إطار `sandbox="allow-scripts"` مع `referrerpolicy="no-referrer"` وتعليمات CSP تمنع `connect-src` و`form-action`.
- ظهور تهيئة `EDU_PLATFORM_INIT` ومعرفين مؤقتين.
- رفض رسائل مصدرها نافذة أخرى، أو ذات أصل مختلف، أو معرف محاولة غير مطابق.
- رفض درجة خارج المجال، وقبول نتيجة صحيحة للتجربة مع عرض رسالة «لم تُحفظ».
- عدم السماح لرسالة النتيجة المكررة باستبدال النتيجة المعروضة.
- تنظيف مستمعي الرسائل وإعادة التمرير عند إغلاق العارض.
- تحميل ملف HTML صالح من `File.text()`.
- نجاح تحليل ملفات JavaScript وكود نموذج HTML.

**طريقة الاختبار:** محاكاة DOM/Window وتشغيل وحدات JavaScript مباشرة؛ لا يُعتبر هذا إثباتًا لسلامة RLS أو عمل المتصفح الفعلي.

## 2. اختبار ربط صفحة الدروس — 11 من 11 ناجحة

- شاشة تسجيل الدخول في وضع المعاينة.
- ظهور زري المعاينة واختيار ملف لدى المدير والمعلم.
- استمرار ظهور أداة استيراد الواجبات القديمة دون تعديل.
- تحميل المثال من `examples/html-activity-example.html` وفتح نافذة المعاينة المعزولة.
- سلامة ترتيب تحميل الوحدات داخل `index.html`.

## 3. اختبار المتصفح الحي — 11 من 11 ناجحة

أُجري بعد نشر التحديث على GitHub Pages، في وضع `?demo=1` وبحساب معلم **تجريبي**، دون بيانات إنتاج:

- ظهور شاشة الدخول والتبديل لدور المعلم ثم فتح لوحة الدروس.
- وجود استيراد واجب HTML القديم إلى جانب أداة المعاينة الجديدة.
- فتح النموذج من زر «تجربة نموذج نحوي» داخل العارض المعزول.
- تهيئة النموذج وظهور السؤالين العربيين.
- اختيار «قرأَ» و«العلمُ»، ثم إرسال نتيجة النموذج.
- ظهور رسالة **«وصلت نتيجة تجريبية: 2 / 2 — لم تُحفظ في المنصة.»** في واجهة العارض.

صفحة عملية الفحص: https://agent.tinyfish.ai/runs/ca5236e6-db75-41b9-891f-c8ad28f1b897

**حدود الفحص:** نجاح عرض النموذج في المتصفح لا يُثبت استحالة اختراق iframe أمنيًا، ولا نجاح تسليم نتائج خادمية؛ كما لم تُختبر ملفات HTML متنوعة أو أدوار الإنتاج الحقيقية.

## 4. ما لم يُختبر بعد

- المتصفح على الهاتف، ولوحات المفاتيح والتمرير في `iframe`.
- استقبال نتيجة فعلية داخل Supabase؛ **لا يُنفّذ حتى الآن**.
- صلاحيات تسجيل نتائج الطلاب وقراءة الملفات والأدوار في RLS.
- توافق وإصلاح عارض ملفات النحو القديمة غير المعزول.

## 5. بوابة الانتقال إلى التسليم الحقيقي

لا تتحول المعاينة إلى واجبات رسمية إلا بعد إنشاء رحلة `assignment` و`attempt` حقيقية، والتحقق الخادمي من الحساب والإسناد والنتيجة، وتجربة ملفات الإنتاج القديمة، مع نسخ احتياطي مكتمل.
